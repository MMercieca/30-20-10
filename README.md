# Intro

A small project to get up to speed on Swift programming. 

I had read about the [30-20-10](https://www.runnersworld.com/training/a20814486/new-workout-the-30-20-10-produces-impressive-results/) interval training program and wanted to try
it out.  unfortunately I couldn't find any apps that allowed for repeated intervals in that pattern.

So I designed a circle progress bar and got up to speed on `NSTimer`.
